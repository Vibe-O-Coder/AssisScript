# Edição histórica de brincadeira

`assis-joke-2.1.0/` preserva a edição de vocabulário Assis/Fodase, com os
compiladores Windows e Linux, seu código-fonte, bibliotecas, exemplos e testes.
Use exclusivamente os binários dessa pasta para esses programas:

```powershell
.\historical\assis-joke-2.1.0\bin\assis.exe run .\historical\assis-joke-2.1.0\exemplos\01_ola.assis
```

Ela foi extraída de `AssisScript_Compilador.zip`, cuja procedência e hash estão
em `ORIGIN.json`. É a versão mais antiga nos arquivos fornecidos (2.1.0);
não foi encontrada uma edição 1.x. Os arquivos extraídos não foram modernizados.

A linguagem atual não aceita esse dialeto, inclusive quando `--legacy` é usado.
Na edição atual, essa opção seleciona o modelo manual de memória em sintaxe
canônica; não reativa palavras ou comentários históricos.
